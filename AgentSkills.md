# Agent Skills

StoryCanon is an [agent skill](https://github.com/SHREE167/storycanon/tree/main/skills/storycanon) plus a local Python MCP engine.

## Install into a novel project

```bash
npx skills add SHREE167/storycanon
```

or:

```bash
npm install github:SHREE167/storycanon
```

Then:

```bash
pip install "git+https://github.com/SHREE167/storycanon.git"
npx storycanon init "your premise" --title "Your Title"
```

Full protocol: `skills/storycanon/SKILL.md`  
Project agent notes: `AGENTS.md`
